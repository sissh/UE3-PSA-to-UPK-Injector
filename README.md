# UE3 PSA to UPK Injector

This tool injects the animation data from a PSA file into a decompressed UPK file. The bones must match between the PSA animation and the UPK animation.

Usage :

`python .\ue3_psa_upk_injector.py --upk {UPK File} --psa-original {Original PSA file} --psa-modified {Edited PSA file} --sequence {SequenceName} --animset {AnimSet} --out {Output UPK file}`

`python .\ue3_psa_upk_injector.py --help`
